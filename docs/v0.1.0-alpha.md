# hiwd company v0.1.0-alpha 本地试用

这个候选版本用 Python 3.9 或以上及其标准库运行。已审阅快照和样本导航随代码提供。本机试用不需要账号、安装 Python 包或付费服务。

## 在 Mac 上试用

打开终端，在仓库根目录执行：

```sh
sh scripts/start_local.sh
```

在 Mac 浏览器打开 [hiwd company 本地入口](http://127.0.0.1:18768/)。保持启动它的终端运行。停用时在同一终端按 Control-C。默认监听 `127.0.0.1:18768`。若端口已被占用，可运行 `sh scripts/start_local.sh --port 18769`，再访问 [替代端口](http://127.0.0.1:18769/)。手机和平板视口可在 Mac 浏览器的响应式模式查看，其他设备不能直接访问这台 Mac 的回环地址。

| 数据与开关 | 本地行为 |
| --- | --- |
| 无缓存、无 SEC 凭据 | 可搜 AAPL、MSFT、NVDA、TSM 的已审阅报告及港/A 样本。其他美股搜索会显示 SEC 访问未开启或来源未可用。 |
| 默认本地路径 | 已审阅快照存入 `local-results/reader.sqlite`。SEC 按需目录与原文缓存为 `local-results/sec-research.sqlite`，核验结果在同路径加 `.reports.sqlite`。 |
| 已有获准缓存 | 把两个数据库放在仅本机可用的位置。用 `sh scripts/start_local.sh --research-cache /绝对路径/sec-research.sqlite` 读用该缓存。覆盖范围和时间取决于文件中实际保存的证据。 |
| 显式启动 SEC 联网 | 仅在另行获得真实项目联系与网络使用授权后，在本机为当前终端设置 `SEC_USER_AGENT`，包含项目名和授权的 SEC 联系信息，然后运行 `sh scripts/start_local.sh --allow-sec`。无变量时启动拒绝。仅设置环境变量时，服务仍离线。按需访问、限流及 403/429 停止规则见 SEC 实验文档。 |

真缓存不随仓库分发。使用上游访问许可允许的本地副本，避免在运行时移动数据库。不要把真实联系地址、数据库或完整原文写进仓库或反馈。 [SEC 按需约束](phase-1c.md#核验缓存与复现)

## 可以试用的内容

| 公司 | 试用范围 |
| --- | --- |
| AAPL | 三份 10-K、四份 10-Q，其中年报保留已审核的业务和分部说明。 |
| MSFT、NVDA | 每家一份已审阅正式年报，财年与证据以报告页为准。 |
| TSM | 年度 20-F 的获准本地核验快照使用新台币和 IASB IFRS。6-K 可看原文及附件入口，缺失核验数字保持空。 |
| COST、KO、JPM | 需要合规官方缓存或单独授权的 SEC 按需连接。本地复跑可核对各自最近已缓存报告、真实行名、原文链接及有覆盖证据的公告目录。 |
| 腾讯、阿里巴巴、贵州茅台、工商银行 | 四样本原文导航。用 00700.HK、09988.HK、600519.SH、601398.SH 搜索。01398.HK 对应工行同一发行人的 H 股。 |

公告提供观测期内的 SEC 申报目录及原文，正文解释尚未验收。港/A 样本维持外链阅读，自动采集、应用内导入与原文镜像均未启用。媒体许可、完整市场覆盖和生产安全待独立验收。
