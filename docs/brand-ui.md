## 实际参考

本地审阅附件包含 `hiwd-desktop-light.jpg`、`hiwd-desktop-dark.jpg` 和 `hiwd-mobile-light.jpg`。公开 PR 保留样式测量、页面来源及组件对应关系，图片通过本地交付。

截图为主站真实渲染而非设计稿。桌面视口 1440×1000、移动 390×844，文件为整页截图，因此高度可能大于视口。深色来自系统/主站主题，浅色通过站内按钮切换验证。只用截图记录既有设计；青苹果照片/二维码不迁入阅读器。

## 可复用样式与适配规则

| 项目 | 主站实测 | hiwd company 的应用 |
| --- | --- | --- |
| 品牌 | 小写 hiwd 字标，青绿色点；浅/深色不同图片 | 正式标题、页眉、manifest、文档统一 `hiwd company`；延用小写字标和青绿色点的组合，原型以系统字体文字组合实现 |
| 字体 | `-apple-system, BlinkMacSystemFont, system-ui, PingFang SC, Helvetica Neue, sans-serif`；正文 16px | 沿用系统中英文字体，无远程字体服务；财务数字启用 tabular-nums |
| 字号与字重 | 主标题 clamp(54px, 5.6vw, 82px)，620；导语 17–18px；导航标题 23–30px、540；正文 15–16px | 阅读器标题缩为 40–64px，正文 16–18px，保留较紧标题与舒展正文；不套主站营销大标题大小 |
| 浅色 | 背景 #f7f6f2；表面 #fff；文字 #18201e；次级 #5f6b67 | 直接作为主题 tokens，弱化装饰，突出原文和阅读 |
| 深色 | 背景 #101312；表面 #181c1b；文字 #eef3f2；次级 #aeb7b4 | 原型提供同源深色主题，切换不改变内容/尺寸 |
| 强调色 | #28d0c1 | 保留品牌色用于线、选中背景；浅色小字链接使用加深版本以满足 4.5:1 对比度，记录为可读性适配，不另换品牌 |
| 留白 | max-width 1240px；桌面 shell 为 100%-72px，中等 100%-40px，≤540px 为 100%-36px | 沿用容器和 1100/540px 断点；长文限制行宽，移动一列，不靠隐藏横向溢出来修复布局 |
| 导航/组件 | 桌面四栏 rail，共用外边框与内分隔线；≤1100px 两列，≤540px 转无外框单列；细线和留白 | 四个栏目转紧凑导航，同一外框/分隔逻辑，移动保留四个可点栏目；财务用列表/表格，不做行情仪表盘 |
| 圆角 | 主图/rail/dialog 24px；小组件 14–16px；brand 8px | 大阅读区域 24px，小控件 14–16px，表格本身不再层层套卡片 |
| 图标 | 普通入口用文字与简单方向符号；无统一第三方图标库证据 | 仅必要按钮和文字，不凭空引入品牌图标系统；原文入口靠明确文案识别 |
| 交互/可达性 | skip link；2px accent focus，offset 4px；主题按钮；ease cubic-bezier(.22,.75,.28,1)；reduced-motion 分支 | 保留 skip/focus、键盘可用导航和主题切换；采用短淡入/状态反馈，减少动态时禁用动画，不隐去正文 |

主站 muted #83908b、浅色 accent 以及某些小号文字不直接用于阅读器的任务关键文字；阅读日期/状态至少 14px、正文至少 16px，需测试对比度。品牌继承不等于复制主站所有可读性取舍。

## 资产与范围

字标来源：首页 `.brand img` 指向 `img/logo.png`（浅色）及 `img/hiwd-logo-white-green-dot-trimmed.png`（深色）。原型使用本地排版及 CSS 青绿点延续字标表现，保留来源路径供视觉对照。不复制主站照片、二维码、文章或第三方人物图像，也不假定这些素材有通用授权。

Phase 0 只完成调研和清单；Issue #3 的本地阅读原型另开分支和 PR，实拍图随本地审阅材料交付。当前主站参考图不能当作原型已完成的截图。
